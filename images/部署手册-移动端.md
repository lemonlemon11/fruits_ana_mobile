# SLD 水果市场销售分析系统 — 移动端 Docker 部署手册

> 文档位置：`fruits_ana_mobile/images/部署手册-移动端.md`
> 日期：2026-09-30

## 1. 部署包说明

本部署包面向「生产服务器已安装 Docker，用户端 `fruits_ana` 已部署」的场景，
提供移动端静态站镜像（单 Nginx 容器，无后端、无数据库、无环境变量）。
移动端接口通过容器内 Nginx 把 `/api/` 反向代理到宿主机 `127.0.0.1:8000` 的
用户端后端（ADR-052 桌面 / 移动分流）。

解压后的目录结构：

```text
fruits_ana_mobile/
└── images/
    ├── fruits-ana-mobile-web.tar
    ├── config/
    │   ├── docker-compose.yml
    │   └── nginx/fruits_ana_mobile.conf
    ├── scripts/
    │   ├── check.sh
    │   ├── build-images.sh
    │   ├── load-images.sh
    │   ├── start.sh
    │   ├── stop.sh
    │   ├── status.sh
    │   └── package.sh
    └── 部署手册-移动端.md
```

## 2. 前置条件

- Linux 服务器，已安装 Docker Engine 和 Docker Compose v2。
- **用户端 `fruits_ana` 已部署且后端运行在宿主机 8000 端口**（登录、看板等
  接口全部来自它）。
- 端口 `54001` 未被占用。

```bash
cd /home/python/workspace/fruits_ana_mobile/images
./scripts/check.sh
```

## 3. 加载镜像

```bash
cd /home/python/workspace/fruits_ana_mobile/images
./scripts/load-images.sh
```

确认镜像存在：

```bash
docker images | grep fruits-ana-mobile-web
```

## 4. 启动与验证

移动端无需配置环境变量，直接启动：

```bash
cd /home/python/workspace/fruits_ana_mobile/images
./scripts/start.sh
./scripts/status.sh
```

验证：

```bash
curl -I http://127.0.0.1:54001/
curl http://127.0.0.1:54001/api/auth/me   # 未登录应返回后端 401 JSON，证明代理链路通
```

移动端访问地址（手机浏览器）：

```text
http://服务器IP:54001
```

说明：

- 桌面端（53000）的移动 UA 分流与 `?desktop=1` 逃生口由用户端前端内联脚本
  实现，本部署无需额外配置。
- 会话 Cookie 与用户端同源（经各自的 Nginx 代理到同一后端），用户端登录的
  账号在移动端同样可用。

## 5. 更新与卸载

更新（新镜像 tar 覆盖 `images/` 后）：

```bash
./scripts/load-images.sh
./scripts/stop.sh
./scripts/start.sh
```

卸载：

```bash
./scripts/stop.sh
docker rmi fruits-ana-mobile-web:local
```

容器不含任何业务数据，卸载无数据清理项。

## 6. 重新构建与打包

如需在开发机重新构建移动端镜像并覆盖 `.tar`，在仓库根目录执行：

```bash
cd /home/python/workspace/fruits_ana_mobile
./images/scripts/build-images.sh
```

生成部署压缩包：

```bash
cd /home/python/workspace/fruits_ana_mobile/images
./scripts/package.sh
```

生成文件：

```text
/home/python/workspace/fruits_ana_mobile_deploy_YYYYMMDD_HHMMSS.tar.gz
```
